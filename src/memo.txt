// 구성
처음접속시 
- 최초 접속시에만 표출 , 웹 설명 페이지 ( 피카츄 이미지 + 말풍선 형식 )
로딩
- 로드될동안 로딩화면 / 로드 3초이내시 : 3초 - 로드된시간 더 로딩  / 그외 정상 로드될동안 대기 
시작화면 ( 시리즈 갤러리 ) 
- 시리즈 목록 로드 (갤러리 형식 => 스크롤시 슬라이드 )
- 시리즈 클릭시 세트 페이지로 이동
세트 화면
- 각 세트들 360도 회전 가능하게 , 세트 클릭시 세트 줌인 , 팩 까기
카드화면 
- 세트 카드들 랜덤 10장 표시
- 카드 클릭시 다음 카드 표출하는 형식 ( 오른쪽 슬라이드 : 다음 , 왼쪽 : 이전  )
- 5장 전체 표출 완료시 개봉결과에 전체 결과 표출 , 카드 갤러리 이동
카드 갤러리
-해당하는 카드 세트팩에서 몇번째 카드 등록됐는지 표시
- 상단 탭형식 ( 보유중인 카드 전체보기 ,세트별로 보기 )
- 하단 카드 목록
